# Cuestionario de descubrimiento: proveedor de insumos para restaurantes

> **Objetivo:** reunir todo lo necesario para diseñar el negocio y su sistema antes de escribir una sola línea de código, desde la estrategia y la operación diaria hasta la arquitectura técnica.

---

## Cómo usar este cuestionario

- **¿Prefieres contestarlo a mano en iPad con Apple Pencil?** Usa `cuestionario-ipad-esencial.pdf` (solo las 93 preguntas críticas) o `cuestionario-ipad-completo.pdf` (todas), en esta misma carpeta.
- **No tienes que contestar todo de una vez.** Empieza por las preguntas 🔴. Con esas ya se puede definir la primera versión (MVP).
- Responde debajo de cada pregunta, en la línea `R:`. Si no lo sabes, escribe **"No sé"** o **"Recomiéndame"**. Eso también es información útil.
- Si una sección no aplica a tu negocio, escribe **"No aplica"** en el título de la sección y sigue adelante.
- Cada pregunta tiene un código (por ejemplo `D-12`) para poder referirnos a ella después.
- Muchas preguntas usan México como ejemplo (SAT, CFDI, COFEPRIS). Si operas en otro país, piensa en el equivalente local.

## Anexo 3. Glosario

| Término | Significado |
|---|---|
| **B2B** | Venta de empresa a empresa (a restaurantes). |
| **B2C** | Venta a consumidor final (al público). |
| **MVP** | Producto Mínimo Viable: la primera versión, con solo lo indispensable para operar y aprender. |
| **SKU** | Cada producto distinto que vendes. "Jitomate por kilo" y "Jitomate caja 20 kg" son 2 SKUs. |
| **Cross-docking** | Comprar y entregar casi sin almacenar. |
| **Marketplace** | Plataforma donde varios proveedores venden y tú cobras comisión. |
| **Peso variable** | Producto cuyo peso real se conoce hasta que se pesa al surtir. |
| **Merma** | Producto que se pierde por daño, caducidad o manejo. |
| **PEPS / FEFO** | Primero en entrar, primero en salir / primero en caducar, primero en salir. |
| **Picking o surtido** | Armar físicamente los pedidos en el almacén. |
| **Hora de corte** | Hora límite para pedir y recibir en la siguiente entrega. |
| **Ventana de entrega** | Rango de horas en el que el cliente puede recibir. |
| **CFDI** | Factura electrónica en México. |
| **PAC** | Proveedor autorizado que timbra (valida) las facturas electrónicas. |
| **Complemento de pago** | CFDI que se emite al recibir un pago de una factura a crédito. |
| **Nota de crédito** | Documento que reduce lo que el cliente debe (por devolución o descuento). |
| **Conciliación** | Cruzar los pagos recibidos en el banco con las facturas del sistema. |
| **PWA** | Página web que se instala y se comporta como una app en el celular. |
| **API** | Forma en que dos sistemas se conectan y se pasan información automáticamente. |
| **Trazabilidad** | Poder seguir un lote desde el proveedor hasta cada cliente que lo recibió. |
